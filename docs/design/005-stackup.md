# 005 · 層疊、阻抗與走線規則

---

## 1. 層疊

沿用上一塊板已驗證的 JLCPCB 四層疊構：

```
        JLC04161H-7628 · 1.6mm

L1  F.Cu      1oz    訊號（差分優先）
    ├─ prepreg 7628  0.2104mm  Er 4.4
L2  In1.Cu    0.5oz  GND 完整平面  ★ 不可分割
    ├─ core          1.065mm   Er 4.6
L3  In2.Cu    0.5oz  電源平面（分割）
    ├─ prepreg 7628  0.2104mm  Er 4.4
L4  B.Cu      1oz    訊號 + 低速
```

**L2 必須是一整片完整 GND。** 所有高速差分都走 L1，參考 L2；
L1 和 L2 之間只有 0.21mm，耦合緊、回流路徑短，這是四層板做高速的關鍵。

L4 的訊號參考 L3（電源平面），而 L3 是分割的 —— **所以 L4 不走高速差分**，
只走低速訊號（I2C、GPIO、按鍵、LED）。

## 2. 阻抗目標

| 訊號 | 阻抗 | 線寬 | 間距 |
|---|---|---|---|
| MIPI DSI | 100Ω 差分 | ⚠ 待 JLCPCB 回算 | ⚠ 待回算 |
| HDMI TMDS | 100Ω 差分 | ⚠ 待回算 | ⚠ 待回算 |
| USB 2.0 HS | 90Ω 差分 | ⚠ 待回算 | ⚠ 待回算 |
| 乙太 TX/RX | 100Ω 差分 | ⚠ 待回算 | ⚠ 待回算 |
| 一般單端 | 50Ω | ⚠ 待回算 | — |

⚠ **線寬必須用 JLCPCB 下單頁的阻抗計算器回算，不能自行假設。**
下單時勾選「阻抗控制」，他們會給對應的線寬/間距表，照那個重畫。

上一塊板的教訓：先畫好再回算會變成整塊重拉，**layout 前先拿到線寬表**。

## 4. 為什麼各訊號的等長要求差這麼多

等長要求來自**上升時間**，不是頻率：

```
臨界長度 = 上升時間 × 傳播速度 / 6
FR4 傳播速度約 150 mm/ns
```

| 訊號 | 上升時間 | 臨界長度 | 等長要求 |
|---|---|---|---|
| HDMI TMDS | ~250 ps | **6 mm** | ±0.15mm |
| MIPI HS | ~150 ps | **4 mm** | ±0.1mm |
| USB HS | ~500 ps | **12 mm** | ±0.15mm |
| RGB 148MHz | ~1.5 ns | **38 mm** | ±5mm |
| MIPI 分支 stub | ~200 ps | **5 mm** | **0Ω 焊盤距主幹 ≤0.5mm** |
| RMII 50MHz | ~2 ns | **50 mm** | ±5mm |
| USB FS（上一塊板） | 4 ns | **94 mm** | 幾乎不用管 |

**這解釋了為什麼上一塊板的 USB 隨便走都能動，而這塊板不行。**

## 5. 區域規劃

```
┌─────────────────────────────────────────┐
│  電源區          │  T113-S3 + 去耦       │
│  DC-DC / LDO     │  （板中央）           │
│  （遠離差分）     │                       │
├──────────────────┼───────────────────────┤
│  乙太            │  RGB 22 條 → IT66121  │
│  PHY + 變壓器    │  （最佔面積的一塊）    │
│  ★ 隔離挖空      │                       │
├──────────────────┼───────────────────────┤
│  USB Type-C ×2   │  HDMI 座 │ MIPI FPC   │
│  USB-A           │          │            │
│  GPIO 排針 28P   │          │            │
└─────────────────────────────────────────┘
```

原則：

1. **DC-DC 遠離差分訊號** —— 開關雜訊是最大的干擾源
2. **接頭沿板邊排列** —— 差分走線從 SoC 到接頭最短
3. **RGB 那 22 條要留大塊連續空間** —— 它們要一起走、一起等長，被切斷就難繞
4. **變壓器隔離區不放任何東西**
5. **MIPI FPC 座與 IT66121 的相對位置是這塊板最關鍵的一段 placement**
   —— PD0~PD9 是 MIPI 與 RGB 共用的，MIPI 必須是主幹直通，IT66121 掛在 0Ω 分支上。
   **IT66121 放得離主幹越近，分支 stub 越短。** 見 [002-display.md](002-display.md) §1.2。

6. **GPIO 排針放板邊，且遠離 MIPI 與 TMDS** —— 排針是最容易被外部誤接的地方，
   28-pin 排針本身也是一排會輻射的長導體。

> v0.1 這裡原本有「WiFi 模組（DNP）放板角 + 天線 keep-out」一條。
> **WiFi 已於 2026-09-19 完全移除**（見 [003-network.md](003-network.md) §6），
> 天線區挖空的問題連帶消失 —— GND 平面現在是完整的一片。

## 6. 鋪銅規則

沿用上一塊板的做法：

```
板邊退縮        0.3mm（JLCPCB 銑床公差 ±0.2mm）
zone clearance  依 DRC 設定
thermal relief  一般焊盤用；大電流與散熱焊盤用 Solid
L2 GND          完整一片，不做任何分割
L3 電源         依電壓域分割，分割線不可跨在任何高速走線正下方
```

⚠ **20H 規則不適用** —— 20 × 1.065mm = 21.3mm，超過板寬的合理比例。
（上一塊板算過同樣的帳。）

## 7. 出圖注意（上一塊板踩過的坑）

```
[ ] kicad-cli 預設不重填鋪銅 —— 出圖前必須在 GUI 裡按 B 重填並存檔
    （實驗證據：移除 filled_polygon 後 In1_Cu.gbr 從 105KB 掉到 4KB）

[ ] 內層 Gerber 檔名不可帶括號
    In1_Cu(GND).gbr → JLCPCB 會判成 2 層板

[ ] Gerber 用 aux 原點，與 CPL 座標系一致

[ ] CPL 用 JLCPCB 官方五欄格式
    Designator, Mid X, Mid Y, Layer, Rotation
    座標帶 mm 後綴，Layer 首字大寫

[ ] --board-plot-params 要帶，否則 subtractmaskfromsilk 與 X2 屬性用 CLI 預設

[ ] BGA/QFP 的 CPL 座標是「焊盤陣列中心」，不一定是本體中心
```

## 8. 驗收

```
[ ] 層疊設定與 JLCPCB 回算值一致
[ ] 所有差分對阻抗與等長符合上表
[ ] L2 GND 為完整一片，無分割
[ ] 沒有任何高速差分走在 L3 分割線正上方或正下方
[ ] RGB 22 條的串聯阻尼電阻已放，靠近驅動端（PD0~PD9 那 10 條要放在 0Ω 之後、IT66121 那側）
[ ] MIPI/RGB 分支的 10 顆 0Ω 焊盤距主幹 ≤0.5mm
[ ] 排針 20 條對外訊號的限流電阻已放
[ ] 變壓器隔離區所有層都已挖空
[ ] 板邊退縮 0.3mm
[ ] DRC violations / unconnected / schematic parity 三項歸零
```
