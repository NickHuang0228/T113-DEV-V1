### 3.3 三個方案的取捨

> **✅ 已選 A（ADV7511）。** 判準見 §0 與 002-display.md §3.1 ——
> 目標從「driver 最省事」改為「driver 工作本身就是練習目標」之後，
> B（TFP410）反而是三個裡最差的：它是 DVI serializer，HDMI 協定層幾乎空白。


#### A. ADV7511KSTZ — 功能最完整，最貴

```
✅ mainline adv7511 driver 成熟,被大量 FPGA/SoC 板用,踩坑的人最多
✅ 輸入上限 165 MHz,與 IT66121 相同,1080p60 沒問題
✅ LQFP-100 有腳可目視,比 QFN-64 好檢查
⚠ 仍有 EPAD,還是得靠 PCBA（006-assembly.md 的結論不變）
⚠ 14×14 本體,和 T113 一樣大,100×100mm 板上要重新配置
❌ $13.75 × 2 = $27.5,是 IT66121 估價的 7 倍
```

##### ✅ 電平問題已解決：3.3V 可以直接驅動

`(ADV7511W Hardware User's Guide Rev.A, p.17 Pin Description)`

```
D[35:0] / CLK / HSYNC / VSYNC / DE
  "Supports typical CMOS logic levels from 1.8V up to 3.3V."
```

**視訊輸入腳 1.8V~3.3V 通吃 → VCC-PD = 3.3V 的決定不必推翻,也不需要電平轉換。**

⚠ 出處是 **ADV7511W**（165MHz 寬溫版）的硬體指南,我們要買的是 `ADV7511KSTZ`。
兩者同家族、同腳位,這條輸入電平規格是家族特性,但**下單前仍應回 ADV7511 自己的
datasheet 核對一次**（ADI 官網的 PDF 直連會擋 curl,要從 DigiKey 等鏡像抓）。

##### ⚠ 但帶出一個新問題：1.8V 軌的電流

`(同上,p.11 Power Supply)`

```
DVDD / AVDD / PVDD / BGVDD   1.8V      1.8V power = 325 mW  →  約 180 mA
DVDD_3V                      3.3V      3.3V power = 1 mW
```

```
001-power.md §2.2 原本的 1.8V 帳：已知約 52 mA
加上 ADV7511 的 180 mA          →  約 232 mA
晶片內建 LDOA 上限               →  260 mA   ← 幾乎貼滿,且 VDD18-DRAM 還是 TBD
```

**→ 外部 1.8V LDO 變成必須,而且不能用 XC6206（典型僅 200 mA）。**
改用 **AP2112K-1.8TRG1**（`C176944`，600 mA，$0.17，庫存 47,449）。

另外 ADI 建議把四個 1.8V 域**分成 3 組獨立的 PCB 電源域並各加 LC 濾波**
（p.41 Figure 21），PVDD（PLL）最敏感。這是額外的 layout 工作量。

##### 電源域淨變化

```
IT66121 方案   3.3 / 1.5 / 0.9 / 1.8 / 1.2   5 組
ADV7511 方案   3.3 / 1.5 / 0.9 / 1.8          4 組   ← 1.2V 消失,但 1.8V 要加大
```

#### B. TFP410PAPR — 最務實，代價是沒有 HDMI 音訊

```
✅ mainline ti-tfp410 driver,而且極簡單（它幾乎是個純 serializer）
✅ $6.28,庫存 142
✅ HTQFP-64 10×10,有腳,焊接難度低於 QFN
✅ 電源只要 3.3V → 省掉 1.2V 那條軌,電源樹回到 4 組
✅ 輸入 1.8V/3.3V 皆可（TFP410 的 IO 電平可選）→ VCC-PD 3.3V 決定不必推翻

❌ 它是 DVI transmitter,不是 HDMI：
     沒有 HDMI audio、沒有 InfoFrame、沒有 HDCP
     插 HDMI 螢幕「會有畫面」（HDMI sink 相容 DVI 訊號）,但沒有聲音
❌ 螢幕的 EDID 會被當成 DVI 裝置,某些電視可能不吃
```

**「沒有 HDMI 音訊」對這塊板的實際影響：本來就有 3.5mm 音訊座。**
HDMI 音訊不是這塊板的學習目標，TMDS layout 才是 —— **而 TMDS 走線完全一樣。**

#### C. MS7210 — 最便宜、footprint 可沿用，但違反原始判準

```
✅ $1.75,庫存 299
✅ QFN-64-EP 9×9,與 IT66121 同封裝 → 008-footprint.md 的驗算可直接沿用
✅ 完整 HDMI（含音訊）
❌ 無 mainline driver —— 這正是當初否決 LT8618SX 的理由
   要自己寫或移植廠商 driver,第一塊 Linux 板不該把風險押在這
```

### 3.4 第四條路：從代理商買停產的 IT66121

Utsource / Veswin / IC-Components 等通路仍有 IT66121FN 庫存（搜尋結果顯示上萬顆）。

```
❌ 與 LCSC/JLCPCB 訂單分離 → 多一筆運費、多一次報關
❌ 停產料的通路貨有仿冒與翻新風險,第一塊板不該引入這個變數
❌ 之後想再做一版買不到
```

**不建議。** 但如果堅持要原設計不動，這是唯一選項。

## 6. 方法筆記

**LCSC 與 JLCPCB 的網頁都需要 JavaScript，`WebFetch` 只會拿到導覽列。**
可用的是 JLCPCB 的零件搜尋 API：

```python
POST https://jlcpcb.com/api/overseas-pcb-order/v1/shoppingCart/smtGood/selectSmtComponentList
{"currentPage":1,"pageSize":25,"keyword":"<料號>","searchSource":"search"}

回傳 data.componentPageInfo.list[]，每筆含：
  componentCode        C 編號
  stockCount           庫存
  componentPrices[]    價格階梯
  minPurchaseNum       MOQ
  noBuyReason          停產／不可購買的原因   ← 最有價值的欄位
  componentSpecificationEn  封裝
  preferredComponentFlag    是否 Preferred
```

⚠ 回傳裡 `componentBrandEn == "JLCPCB Assembly"` 的項目是 JLCPCB 內部的組裝品項，
價格固定 `$0.0396`，**不是真實零件，要過濾掉**。

**`noBuyReason` 這個欄位是這次查證的關鍵** —— 如果只看 `stockCount == 0`，
會以為 IT66121 只是暫時缺貨，等補貨就好。
是 `"This product is no longer manufactured."` 這句話把它從「缺貨」變成「要改設計」。

```
規則：查料況不能只看庫存數字,要看停產標記。
      庫存 0 有兩種意思,差別是「等一週」還是「重畫原理圖」。
```
