# 006 · 組裝策略、工具與備品

---

## 1. 三種配置

PCB 最低量就是 5 片，**PCBA 貼幾片自己選**，剩下的當裸板寄回。

| | 全貼 2 片 | **貼 1 片 + 自焊 2 片** | 全自焊 |
|---|---|---|---|
| PCB 5 片 + 阻抗 | $20 | $20 | $20 |
| PCBA | $53 | **$35** | $0 |
| LCSC 自購零件 | — | **$45**（2 片份 + 備品） | $70 |
| 鋼網 | — | **$8** | $8 |
| 合併運費 | $18 | $18 | $18 |
| **合計** | $91 | **$126 ≈ NT$4,060** | $116 ≈ NT$3,740 |
| 拿到手 | 2 貼好 + 3 裸板 | **1 貼好 + 2 自焊 + 2 備用** | 5 片全自焊 |

**選中間那欄。** 理由不是省錢，是除錯：

```
1 片專業貼片   →  黃金參考。它不開機就一定是設計問題，不是虛焊
2 片自己焊     →  練手，焊壞不影響進度
2 片裸板       →  留給改版，或之後補料
```

---

## 2. 為什麼「有一片確定焊得好」很重要

```
JLCPCB 貼片   焊接品質穩定  →  不開機 = 設計問題
自己手焊      焊接品質未知  →  不開機 = 設計問題？還是虛焊？
```

128 隻腳裡有一隻虛焊，症狀可能是「開機了但 USB 不通」或「跑十分鐘後當機」——
那種間歇性故障會吃掉好幾天，最後可能發現只是焊錫問題。

**第一塊 Linux 板最不該做的就是增加變因。**

---

## 3. 零件從哪來

JLCPCB **不會把多餘零件寄給你**（按貼裝量採購），自焊的部分要另外買。

```
嘉立創集團 ─┬─ JLCPCB（PCB + PCBA）
            └─ LCSC（零件）
```

**兩邊訂單可合併出貨，運費只付一次。** 否則多一筆國際運費就 $15~20。

⚠ 合併方式與政策下單時確認（有時結帳頁勾選，有時要開 ticket）。

---

## 4. 鋼網 —— CP 值最高的 $8

```
JLCPCB 出 PCB 時加購鋼網   ~$8
```

有鋼網 + 錫膏，QFP128 的 128 隻腳可以**一次刷上、一次回流**。
沒鋼網的話，0.4mm pitch 要手工上錫膏均勻，幾乎不可能。

**自焊方案裡這一筆一定要加。**

---

## 5. 工具：優先順序

```
好烙鐵  >  熱風槍  >  加熱台
```

### 烙鐵（最常用）

```
T12 系列   NT$800~1,500   可換頭、升溫快
```

QFP128 的拖焊、清橋、補線、改線 —— **實際使用時間比熱風槍多十倍**。
預算只夠一樣，先買好烙鐵。

### 熱風槍（不可取代）

```
858D / 858D+    NT$800~1,200   入門，夠用
YIHUA 995D      NT$1,500       熱風 + 烙鐵二合一
```

它的價值在**拆件與返工**：

| | 加熱台 | 熱風槍 |
|---|---|---|
| 整片回流 | ✓ 最擅長 | ✗ |
| **拆單顆元件** | **✗ 做不到** | **✓ 只有它能做** |
| 吹跑 0402 | 不會 | 會 |

**第一次焊自己設計的板子，一定會有要拆要修的地方。** QFN 歪了、QFP 橋了、元件裝錯位 ——
沒有熱風槍就卡死。

### 加熱台：先別買

**有個容易忽略的限制 —— 面積：**

```
MHP30      30×30mm   ← 只能焊小模組
MHP50      50×50mm   ← 仍小於你的板子
你的板子   100×100mm
```

要整片回流 100×100mm，便宜的迷你加熱台全部不夠用，需要：

```
大面積加熱台        NT$3,000~4,000
或 T-962 回流焊爐   NT$6,000
```

算一下帳：**買回流爐 NT$6,000 vs JLCPCB 貼一片 ≈ NT$1,450。**
除非要做很多塊板，否則不划算。

## 6. QFN 的真相：其實該交給 SMT

```
RTL8201F QFN32 底部有散熱焊盤
  只用熱風槍            熱要從側面穿透到底部，得吹很久
                        → 板子烤焦、旁邊元件被吹跑、焊盤起泡
  加熱台預熱 + 熱風      底部本來就熱了，熱風只補最後 30°C
```

**「加熱台 + 熱風槍」才是 QFN 的標準組合，單獨哪一個都很勉強。**

反過來說：QFN 就是不該手焊的封裝。這也是「至少貼 1 片」的理由之一 ——
讓 SMT 處理 QFN32 和 QFP128，你手焊的那幾片可以接受較低良率。

## 7. 備品策略

```
T113-S3    買 3~4 顆   ← QFP128 焊壞一顆就沒了，絕不能省
IT66121    買 3 顆
小 IC      CH340N、LDO 之類買 5 顆，單價低
被動件     0402 最小包裝通常 50~100 顆，本來就會多
接頭       按片數買，RJ45 / HDMI / Type-C 都不便宜
```

**主晶片的備品不能省。** 焊到一半發現腳斷了，沒備品就整個停擺，還要再等兩週國際運送。

---

## 8. 焊接順序

```
1. QFP128 / QFN     最難、最矮，先焊
                    壞了早知道，不浪費後面的工
2. 小 IC / DC-DC
3. 被動件 0402
4. 接頭（最高）      最後焊，否則會擋住烙鐵
```

剛好符合「由矮到高」的通則，同時滿足「先驗證最難的」。

**一次只焊一片，測完再焊下一片。**
第一片踩到的坑（錫膏量、風槍溫度、哪個角容易翹）直接用在第二片，良率會明顯提升。

---

## 9. 驗收

```
[ ] 下單時勾選鋼網加購
[ ] PCBA 數量設 1 片
[ ] LCSC 零件訂單建立，與 JLCPCB 訂單合併運費
[ ] 主晶片備品數量確認（T113 ≥3、IT66121 ≥3）
[ ] 收到板子後，先測 SMT 那片，確認設計無誤再開始手焊
```
