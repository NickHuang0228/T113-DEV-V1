# 006 · 組裝策略、工具與備品

版本：v0.2 · 2026-09-18（讀完 datasheet 後改採「部分貼裝」，取代 v0.1 的「貼 1 片 + 自焊 2 片」）

## 1. 四種配置

PCB 最低量就是 5 片，**PCBA 貼幾片、貼哪些零件自己選**，剩下的當裸板寄回。

JLCPCB 的 PCBA **只貼 BOM 裡列出的零件**，沒列的位置留空 —— 這開出第四個選項。

| | 全貼 2 片 | 貼 1 片 + 自焊 2 片 | 全自焊 | **部分貼裝 ×3** |
|---|---|---|---|---|
| JLCPCB 貼什麼 | 全部零件 | 全部零件 | — | **只貼 3 顆難焊 IC** |
| PCB 5 片 + 阻抗 | $20 | $20 | $20 | $20 |
| PCBA 服務費 | ~$49 | ~$48 | $0 | **~$21** |
| LCSC 自購零件 | — | $45 | $70 | $45 |
| 鋼網 | — | $8 | $8 | **不需要** |
| 合併運費 | $18 | $18 | $18 | $18 |
| **合計** | ~$87 | ~$139 | ~$116 | **~$104 ≈ NT$3,330** |
| 拿到手 | 2 貼好 + 3 裸板 | 1 貼好 + 2 自焊 + 2 備用 | 5 片全自焊 | **3 片主晶片貼好 + 2 裸板** |

**選最右欄。**

```
3 片主晶片貼好  →  三片都是黃金參考，不開機一定是設計問題
被動件自己焊    →  可觀測、可重焊，練手但零風險
2 片裸板        →  留給改版，或之後補料
```

### 1.1 為什麼從 v0.1 改掉

**① 三顆主要 IC 全部有底部焊盤，全部不可目視檢查**

```
T113-S3    eLQFP128 + EPAD(pin 129)   ← 這是晶片唯一的數位地，不焊完全不會動
ADV7511    LQFP-100 14×14，**無 EPAD**  ← v0.4 換料；0.5mm pitch 有腳，可手焊
RTL8201F   QFN32 + 散熱焊盤
```

T113-S3 的 128 隻腳裡**只有 1 支 AGND，沒有任何數位 GND**`(DS §4.1 p.23)`，
21 支電源的回流電流全部走 EPAD。三種失敗模式都看不見：

```
EPAD 不焊     不開機，量各軌電壓全對，查不出來
EPAD 焊一半   開得起來但間歇當機、DDR 出錯（DDR 在封裝內，最難查）
EPAD 錫太多   晶片被墊高 → 128 隻腳同時虛焊，但目視完全正常
```

**把「不可觀測的焊點」外包，「可觀測的」留給自己** —— 跟當初選 eLQFP 不選 BGA
是同一個判斷標準：**選可觀測性**。

**② 部分貼裝反而更便宜**

JLCPCB 的 PCBA 費用幾乎全在 **Extended part 上料費 $3.07/種**，跟貼幾片、幾個焊點關係很小：

```
只貼 3 顆 IC   →   3 種 × $3.07 = $9.21
全部零件       →  ~12 種 × $3.07 = $36.84
多貼 2 片的焊點成本 = 227 joints × 2 × $0.0016 = $0.73     ← 可以忽略
```

官方價目表（2026-09-09 版，Economic PCBA）：

```
Setup fee                $8.18   每單一次
Stencil                  $1.53
Confirm Parts Placement  $0.45
Feeder Loading           $3.07 / 每種 Extended 料（Basic 免費）
SMT Assembly             $0.0016 / joint
Manual Assembly          $0.0164 / joint  + Hand-soldering Labor $3.58/單
```

⚠ 料號種類數（12）是估的，下單前用實際 BOM 重算。
⚠ 接頭（HDMI / Type-C / RJ45 / microSD / FPC）多半算 Manual Assembly，貴 10 倍，
   本來就該自己焊。

### 1.2 代價

```
① 鋼網用不上了    IC 已貼好，鋼網壓不平 → 80 顆被動件 × 3 片要烙鐵手焊
                  累，但焊壞看得見也重焊得了

② 熱風不能用      在已貼好的 IC 旁邊作業，只能用烙鐵
```

⚠ **建議被動件改用 0603 而非 0402** —— 手焊難度差一個等級，
而面積對 100×100mm 的板子完全不是問題。**這要在畫原理圖前決定。**

## 2. 為什麼主晶片一定要交給 SMT

```
JLCPCB 貼片   焊接品質穩定  →  不開機 = 設計問題
自己手焊      焊接品質未知  →  不開機 = 設計問題？還是虛焊？
```

128 隻腳裡有一隻虛焊，症狀可能是「開機了但 USB 不通」或「跑十分鐘後當機」——
那種間歇性故障會吃掉好幾天，最後可能發現只是焊錫問題。

**而 EPAD 的失敗更糟：完全無法目視檢查，只有 X-ray 看得到。**

```
可觀測的焊點   焊壞了看得出來、量得出來、重焊得了   →  自己焊
不可觀測的     只能靠 X-ray 或報廢                  →  外包
```

**第一塊 Linux 板最不該做的就是增加看不見的變因。**

## 3. 零件從哪來

JLCPCB **不會把多餘零件寄給你**（按貼裝量採購），自焊的部分要另外買。

部分貼裝的分工：

```
JLCPCB 買 + 貼    T113-S3 / ADV7511 / RTL8201F   × 2 片份
LCSC 自己買       被動件 0603 / 接頭 / 晶振 / 小 IC / 主晶片備品
```

```
嘉立創集團 ─┬─ JLCPCB（PCB + PCBA）
            └─ LCSC（零件）
```

**兩邊訂單可合併出貨，運費只付一次。** 否則多一筆國際運費就 $15~20。

⚠ 合併方式與政策下單時確認（有時結帳頁勾選，有時要開 ticket）。

## 4. 鋼網 —— 採用部分貼裝後就不需要了

```
JLCPCB 出 PCB 時加購鋼網   ~$8
```

鋼網解決的是「細間距零件手工上錫膏不可能均勻」的問題。

**但鋼網必須壓在平的裸板上** —— 部分貼裝後，三顆 IC 已經焊在板上，
鋼網放不平，刷不了。

```
v0.1（自焊主晶片）   鋼網必買
v0.2（部分貼裝）     不需要，被動件用烙鐵手焊
```

⚠ 除非之後改回自焊主晶片，否則**下單時不要加購鋼網**。

## 5. 工具：優先順序

```
好烙鐵  >  熱風槍  >  加熱台
```

### 烙鐵（最常用）

```
T12 系列   NT$800~1,500   可換頭、升溫快
```

eLQFP128 的拖焊、清橋、補線、改線 —— **實際使用時間比熱風槍多十倍**。
預算只夠一樣，先買好烙鐵。

### 熱風槍（不可取代）

```
858D / 858D+    NT$800~1,200   入門，夠用
YIHUA 995D      NT$1,500       熱風 + 烙鐵二合一
```

它的價值在**拆件與返工**：

| | 加熱台 | 熱風槍 |
|---|---|---|
| 整片回流 | ✓ 最擅長 | ✗ |
| **拆單顆元件** | **✗ 做不到** | **✓ 只有它能做** |
| 吹跑 0402 | 不會 | 會 |

**第一次焊自己設計的板子，一定會有要拆要修的地方。** QFN 歪了、QFP 橋了、元件裝錯位 ——
沒有熱風槍就卡死。

### 加熱台：先別買

**有個容易忽略的限制 —— 面積：**

```
MHP30      30×30mm   ← 只能焊小模組
MHP50      50×50mm   ← 仍小於你的板子
你的板子   100×100mm
```

要整片回流 100×100mm，便宜的迷你加熱台全部不夠用，需要：

```
大面積加熱台        NT$3,000~4,000
或 T-962 回流焊爐   NT$6,000
```

算一下帳：**買回流爐 NT$6,000 vs JLCPCB 貼一片 ≈ NT$1,450。**
除非要做很多塊板，否則不划算。

## 6. 底部焊盤的真相：全部交給 SMT

```
T113-S3   eLQFP128 + EPAD
ADV7511   LQFP-100，無 EPAD，0.5mm pitch
RTL8201F  QFN32 + 散熱焊盤

  只用熱風槍            熱要從側面穿透到底部，得吹很久
                        → 板子烤焦、旁邊元件被吹跑、焊盤起泡
  加熱台預熱 + 熱風      底部本來就熱了，熱風只補最後 30°C
```

**「加熱台 + 熱風槍」才是底部焊盤的標準組合，單獨哪一個都很勉強。**

eLQFP 比 QFN 多一條救命路線（**背面 via 補焊**：從板子背面用烙鐵把錫灌進 thermal via），
但那條路跟「thermal via 要 plugged」互斥，而 plugged 才是貼片的正確做法。

```
A. 鋼網 + 錫膏 + 回流   EPAD 開口做網格狀，錫膏覆蓋率 50~70%，via 必須 plugged
B. 背面 via 補焊        via 不能塞死
                        A 與 B 不能並存 —— layout 階段就要選
```

**本專案採用 A，三顆全部交給 JLCPCB。** 詳見 001-power.md §7.2。

## 7. 備品策略

```
T113-S3    JLCPCB 貼 3 片份 + LCSC 另備 1~2 顆   ← 改版或補焊時要用
ADV7511    ⚠ 不同 —— 無 EPAD，焊點全部可目視、可補焊

### ⚠ v0.4 的重新盤點：只剩兩顆非 PCBA 不可

`(ADV7511 HW User's Guide Rev.D §5.1 p.21 —— 封裝是 [LQFP]，不是 [LQFP_EP])`

```
T113-S3    eLQFP128  EPAD 5.72×5.72  = 唯一的數位地   → 必須 PCBA，無可討論
RTL8201F   QFN-32    EPAD 3.35×3.35                  → 建議 PCBA
ADV7511    LQFP-100  無 EPAD，pitch 0.50，有腳        → ★ 可以自己焊
```

**ADV7511 的焊接難度等同上一塊板焊過的 LQFP** ——
0.5mm pitch 比 T113 的 0.4mm 寬鬆，而且沒有看不見的底部焊點。
拖焊 + 助焊劑 + 放大鏡就能處理，出問題還可以目視找到並補焊。

⚠ **但本專案仍把它交給 PCBA**，理由不是難度，是**成本結構**：

```
JLCPCB 的 PCBA 服務費是「每片固定 + 每點」，已經為了 T113 與 RTL8201F 付了固定費
多貼一顆 ADV7511 的邊際成本很低（約 $1~2/片）
自己焊要多買一次零件、多一道工序、多一個出錯來源
```

**真正的價值在於「它是可補救的」** —— 如果 PCBA 把 ADV7511 焊歪了，
我看得到、也修得了；T113 的 EPAD 焊不好則只能報廢。

```
→ 風險分布改變：v0.3 認為三顆都是「焊壞就報廢」，實際只有 T113 是
```
RTL8201F   同上
小 IC      CH340N、電源 IC 之類買 5 顆，單價低
被動件     0603 最小包裝通常 50~100 顆，本來就會多（3 片份要算清楚）
接頭       按片數買，RJ45 / HDMI / Type-C 都不便宜
```

⚠ 部分貼裝的話，**三顆主 IC 的料要走 JLCPCB**（貼片用料必須跟他們買），
LCSC 那邊只買備品。兩邊訂單仍可合併運費。

**主晶片的備品不能省。** 焊到一半發現腳斷了，沒備品就整個停擺，還要再等兩週國際運送。

## 8. 焊接順序

部分貼裝之後，三顆主 IC 已經在板上，你的順序是：

```
1. 小 IC / 電源 IC   先讓電源能上，量完各軌再往下
2. 被動件 0603       由矮到高
3. 接頭（最高）       最後焊，否則會擋住烙鐵
```

**強烈建議：焊完電源就先量各軌電壓與上電時序，確認 OK 再焊其餘零件。**
電源錯了的話，後面全部白焊，而且可能燒掉已經貼好的主晶片。

**一次只焊一片，測完再焊下一片。**
第一片踩到的坑（錫膏量、風槍溫度、哪個角容易翹）直接用在第二片，良率會明顯提升。

## 9. 驗收

```
[ ] PCBA 數量設 3 片
[ ] BOM 只列 T113-S3 / ADV7511 / RTL8201F 三顆，其餘留空
[ ] 鋼網不加購（用不到）
[ ] 被動件確認為 0603
[ ] EPAD 的 thermal via 已設為 plugged（不是 tented、不是開放）
[ ] LCSC 零件訂單建立（被動件 + 接頭 + 備品），與 JLCPCB 訂單合併運費
[ ] 主晶片備品數量確認（T113、ADV7511、RTL8201F 各 +1~2 顆）
     ⚠ T113 $22.25 / ADV7511 $13.75，備品成本比 v0.2 估算高很多
[ ] 收到板子後，先焊電源、量各軌與上電時序，再焊其餘零件
```
