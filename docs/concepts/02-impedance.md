# 概念 ② 阻抗控制在控什麼

**狀態：✅ 已懂**（2026-09-23）

> 承接 [概念 ①](01-return-path.md)。同樣是「訊號線 + 正下方參考平面」這個結構：
> ① 講電流怎麼回去，② 講訊號在上面感受到多大阻力。是同一個東西的兩面。

---

## 📖 導讀：只要抓住這三點

這條比 ① 抽象，因為它牽涉到「銅線在高頻下行為完全不同」這個反直覺的事實。
**其他段落都是這三點的衍生，先抓這三點就好：**

```
① 高頻時，銅線不再是「導線」，是「傳輸線」
   低頻：一條線兩端永遠同電位，電阻 0.01Ω
   高頻：訊號是一個「波」在線上前進，線的前後端可能電位不同

② 阻抗是「訊號前進時感受到的阻力」，不是電阻
   它不發熱、不消耗能量
   它由幾何決定：線多寬、離參考平面多遠

③ 阻抗突然改變的地方會「反射」
   跟聲音從空氣進到水裡會反彈是同一件事
   反射回來的能量會疊在原訊號上 → 接收端看到振鈴、誤判 0/1
```

### 最容易卡住的地方

**「為什麼銅線會有阻抗，而且不是電阻？」**

一個幫助理解的角度：想像水管。

```
水管的粗細      ←→  阻抗 Z₀
水管內壁的摩擦   ←→  電阻 R
```

水管粗細改變的地方，水流會產生反彈（水錘）—— 那跟管子本身「好不好流」無關，
純粹是**截面改變**造成的。阻抗就是這個「截面」，電阻才是「摩擦」。

所以一條完全沒有電阻的超導體，一樣有特性阻抗。**兩者是不同的東西。**

---

## 為什麼一條銅線會有「阻抗」

```
低頻   銅線就是導線，電阻 0.01Ω，沒什麼好談
高頻   銅線變成「傳輸線」
```

分界點就是臨界長度（見概念 ③）。

變成傳輸線之後，訊號前進時會「看到」一個瞬時阻抗：

```
        L = 單位長度電感   ← 由迴路面積決定（概念 ①）
Z₀ = √(L/C)
        C = 單位長度電容   ← 訊號線與參考平面之間的電容
```

⚠ **Z₀ 不是電阻，它不消耗能量。** 它是「訊號前進時感受到的阻力」。

---

## 另一個角度（比公式好懂）

不用 √(L/C)，改問一個問題：**訊號剛出發的瞬間，驅動端「看到」什麼？**

```
   驅動端          訊號走到這          接收端
   ┌───┐    ██████▶                   ┌───┐
   │ U1│────────────────────────────── │ U2│
   └───┘                              └───┘
     ▲                                   ▲
   我要輸出多少電流？              它還不知道這裡接了什麼
```

訊號才走了 1mm，**驅動端無法知道另一端接的是什麼** —— 開路？短路？100Ω？
那個資訊還沒傳回來（要等來回一趟的時間）。

**那它憑什麼決定輸出多少電流？憑這條線本身的特性：**

```
I = V / Z₀
```

**這就是特性阻抗的物理意義：訊號出發瞬間，驅動端看到的負載。**

它不是「線的電阻」，是「這條線吃電流的胃口」。就算另一端開路（直流電阻無限大），
出發瞬間驅動端還是會輸出 `V/Z₀`。

### 胃口從哪來

訊號前進時在做一件事：**把走線充電到 V 伏特**（相對於正下方的地平面）。

```
        ← 已充電 →  ← 正在充電
    ████████████████▓▓░░░░░░░░░░░░░░░░
    ═══════════════════════════════════  GND 平面
```

充電需要電荷，電荷流動就是電流。**每前進 1mm 要多少電荷，取決於那 1mm 的電容。**

```
線寬變寬       →  對地電容變大  →  每 mm 要更多電荷  →  胃口大  →  Z₀ 低
離地平面變遠   →  對地電容變小  →  每 mm 要較少電荷  →  胃口小  →  Z₀ 高
```

---

## 它由幾何決定

```
        ← W →
    ████████████     訊號線（線寬 W、銅厚 T）
         ↕ H         介質（厚度 H、介電常數 Er）
    ═══════════════  參考平面

    W 變寬   →  C 變大            →  Z₀ 變低
    H 變厚   →  C 變小、L 變大     →  Z₀ 變高
    Er 變大  →  C 變大            →  Z₀ 變低
```

H 和 Er 由疊構決定（本專案已選 JLC04161H-7628），唯一能調的是 W。

**所以「控制阻抗」＝「控制線寬」。**

---

## 為什麼要控制

阻抗不連續的地方會**反射**：

```
訊號 ──────▶│──────
   Z₀=50Ω   │  Z₀=75Ω
            │
        ◀───┘ 一部分能量彈回來
```

跟波在繩子上跑、碰到粗細改變處會彈回來是同一件事。

後果：

```
訊號邊緣出現台階、振鈴  →  接收端誤判 0/1
                        →  HDMI 花屏、USB 列舉失敗、MIPI 點不亮
```

**每一處幾何改變都是潛在反射點**：走線本身、接頭、via、焊盤、分支。

這就是為什麼：

```
002-display.md   MIPI 線上不能有串聯電阻、不能有 AC 耦合電容
005-stackup.md   0Ω 分支的 stub 要 ≤0.5mm
```

分支（stub）是最容易忽略的反射源 —— 訊號跑到分支點會分流，一部分跑進岔路、
撞到開路的末端、再反射回主幹。stub 越短，這個效應越小。

---

## 為什麼線寬要 JLCPCB 回算

阻抗由 W、H、Er、T 決定，其中三個是**製程參數**：

```
H   prepreg 壓合後的實際厚度，不等於標稱值
Er  隨頻率變化，而且每批料略有差異
T   電鍍後的實際銅厚
```

**只有板廠知道自己的實際參數。** 自己用公式算的線寬，和他們做出來的阻抗會對不上。

流程：

```
下單時勾選阻抗控制  →  他們給線寬/間距表  →  照那個畫
```

`005-stackup.md` 寫的「**layout 前先拿到線寬表**」就是這個。
先畫再回算會變成整塊重拉 —— 上一塊板的教訓。

---

## 這塊板的阻抗目標

```
MIPI DSI    100Ω 差分
HDMI TMDS   100Ω 差分
USB 2.0      90Ω 差分    ← 只有這個不一樣，USB 規範就是 90
乙太 TX/RX  100Ω 差分
一般單端     50Ω
```

**為什麼是這些數字？** 不是算出來的，是**規範規定的**。

線的另一端（螢幕、面板、網路設備）也照同一個數字做，
兩邊都是 100Ω，在接頭處才不會反射。阻抗匹配是雙方約定，不是單方最佳化。

---

## 四個容易漏掉的點

### ① 你能調的只有線寬（和間距）

```
W  線寬      ✅ layout 時能調，這是唯一的旋鈕
S  間距      ✅ 差分才需要
H  介質厚度  ❌ 選疊構時就鎖死（本專案 L1→L2 = 0.2104mm）
Er 介電常數  ❌ 材料決定
T  銅厚      ❌ 製程決定
```

⚠ **不要說「板厚」** —— 整塊板 1.6mm 跟阻抗沒關係。
決定阻抗的是「這條線離它的參考平面多遠」，也就是 L1 到 L2 的 0.2104mm。

### ② 差分阻抗 ≠ 2 × 單端阻抗

```
   ← W →  ← S →  ← W →
  ██████         ██████     兩條線之間有電場耦合
  ═══════════════════════   GND
```

兩條線帶 +V 和 −V，彼此之間也有電場。這個耦合讓差分阻抗**低於**兩倍單端值。

```
間距 S 變窄  →  耦合變強  →  差分阻抗變低
```

實務上 100Ω 差分大約是兩條各 55~60Ω 單端配特定間距。
**所以板廠給的是「線寬 + 間距」兩個數字，而且間距要從頭到尾一致。**

### ③ 換層 = 換阻抗

高速線換層有兩個問題疊在一起：

```
回流路徑斷了（概念 ①）  ＋  參考平面變了、阻抗跟著變
```

所以規則是「高速差分盡量不換層，非換不可就在旁邊加 GND via」。
差分對的 P 和 N **必須走同一層**，換層也要一起換。

### ④ 阻抗有公差，不要追求完美

```
JLCPCB 阻抗控制典型公差  ±10%
100Ω 差分 → 實際 90~110Ω 都算合格
```

真正會出事的是**階躍式破壞**，不是百分之幾的偏差：

```
突變     某一段突然變成 60Ω
stub     分支造成的反射
跨分割   回流沒路走
```

**把力氣花在消除突變，不是把線寬算到小數第三位。**

⚠ 另外：阻抗控制算出的線寬通常比一般訊號線**粗**，13 對差分會吃掉可觀面積。
規劃 placement 時就要留這個空間 —— 這是 `007-pinmap.md` 說「pin map 要和 placement
草圖一起迭代」的原因之一。

---

## 一句話

**阻抗由線寬決定，線寬由板廠給，阻抗不連續就反射。**
