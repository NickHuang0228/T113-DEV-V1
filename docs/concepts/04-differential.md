# 概念 ④ 差分訊號為什麼成對

> 用兩條線傳一個訊號，腳位翻倍、走線翻倍、layout 要求更嚴格。**值得嗎？**

---

## 單端訊號的三個問題

單端就是一條線，電壓**相對於 GND**。接收端：高於門檻是 1，低於是 0。

```
① 雜訊直接疊上去    接收端分不出是訊號還是雜訊
② 地彈             收發兩端 GND 不同電位，差 0.2V 訊號就偏移 0.2V
③ 輻射             回流走地平面，迴路面積大 → 天線
```

---

## 差分的做法

兩條線，P 和 N 互為反相。**接收端只看兩者的差值，不管絕對電位。**

```
P = 1.2V, N = 1.0V  →  差 +0.2V  →  判為 1
P = 1.0V, N = 1.2V  →  差 −0.2V  →  判為 0
```

---

## 核心機制：共模抑制

兩條線靠得很近，外界干擾打進來時**兩條受到幾乎一樣的影響**：

```
干擾前        P = 1.2   N = 1.0   →  差 = +0.2
              ↓ 干擾 +0.5V 打進來
干擾後        P = 1.7   N = 1.5   →  差 = +0.2   ← 沒變
```

地彈同理：接收端 GND 高 0.2V，兩條都偏移 0.2V，差值不受影響。

**差分訊號自帶參考，不依賴「共同的乾淨地」。**

---

## ★ 因果順序（最容易搞混的地方）

這是一條鏈，不是兩個並列的特性：

```
① 兩條線靠近       →  受到相同的干擾（共模）
② 只看差值         →  共模被抵銷
③ 得到抗雜訊能力    ← 到這裡都是「機制」
④ 把這能力換成「更小的擺幅」   ← ★ 這才是「目的」
⑤ 小擺幅 → 邊緣可以很陡 → 跑得到 Gbps
```

**抗干擾能力不是拿來「更安全」，是拿來「換速度」。**

```
你把煞車升級了
  → 不是為了更安全地開 60 km/h
  → 是為了能開 120 km/h
```

工程師拿到共模抑制後，沒有選擇「維持 3.3V 擺幅但更穩」，
而是「擺幅砍到 200mV，把省下的餘裕換成速度」。

**只是要抗干擾的話，單端加濾波、加屏蔽也能做。
差分不可取代的地方，是它讓 200mV 這種擺幅變得可行。**

```
單端 CMOS    0 ~ 3.3V 擺幅
MIPI HS      200 mV 差分      小 16 倍
```

小擺幅的三個好處：

```
更快    電容充放電的電荷少 → 邊緣陡 → Gbps
省電    功耗 ∝ V²，擺幅小 16 倍 → 差兩個數量級
低 EMI  電壓變化小，加上磁場互相抵銷
```

---

## 這一條解釋了所有差分 layout 規則

共模抑制的前提是**兩條線受到相同的干擾**。所有規則都在維護這個前提：

| 規則 | 為什麼 |
|---|---|
| 兩條要靠得近（緊耦合） | 距離不同，受到的干擾就不同 |
| 對內等長 ±0.1mm | P 比 N 早到的那段時間，差值是錯的（概念 ③） |
| 必須走同一層 | 表層和內層傳播速度不同 |
| 對稱走線，不要一條繞大彎 | 繞彎那條環境不同 |
| 中間不要插入單一元件 | 破壞對稱性 |

**一旦兩條線的環境不對稱，共模抑制就打折。**

---

## 磁場抵銷

```
P 線電流 →→→→→→
N 線電流 ←←←←←←
```

大小相等、方向相反的電流，磁場互相抵銷 —— 這是差分低輻射的物理原因，
也是兩條線越近效果越好的理由。

---

## ⚠ 澄清：差分仍然需要地平面

常見誤解：「差分的回流走另一條線，所以不需要地平面」。

**理論上對，實務上錯：**

```
① 耦合不可能 100% —— 總有共模成分
② 共模成分需要地平面回流
③ 地平面提供阻抗參考 —— 沒有它 Z₀ 無從定義
```

概念 ① 對差分一樣適用：**正下方還是要有連續的銅。**

---

## 對照本專案的 13 對

| 介面 | 擺幅 | 特點 |
|---|---|---|
| MIPI HS | **200 mV** | 最小擺幅，最快邊緣 |
| HDMI TMDS | ~500 mV | 接收端內建 50Ω 終端 |
| USB 2.0 HS | ~400 mV | |
| 乙太 TX/RX | ~1 V | **經變壓器，兩端完全電氣隔離** |

乙太是差分的極致應用：**透過變壓器，收發兩端連 GND 都不共用**，
完全沒有共同參考也能通訊。這也是變壓器下方地平面要挖空的原因（概念 ①）——
那個隔離是刻意的。

---

## MIPI 的特殊性：同一對線兩種模式

```
HS 模式   200 mV 差分    傳像素資料
LP 模式   1.2 V 單端     傳命令、進出低功耗
```

**同一對銅線，一下子當 200mV 差分傳輸線，一下子當 1.2V 單端訊號。**

這解釋了 `002-display.md` 的兩條禁令：

```
不能加 AC 耦合電容   LP 模式需要直流路徑
不能加串聯電阻       破壞 HS 阻抗匹配，也影響 LP 準位
```

**MIPI 是所有差分介面裡 layout 最嚴格的**，因為它要同時滿足兩套電氣要求。

---

## 一句話

**兩條線靠得近、只看差值 → 換來抗雜訊能力 → 這能力被拿去支撐極小的擺幅 →
小擺幅才跑得到 Gbps。**
