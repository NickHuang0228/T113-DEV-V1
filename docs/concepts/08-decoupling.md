# 概念 ⑧ 去耦電容在做什麼

---

## 問題：晶片吃電不是平穩的

數位晶片在時脈邊緣**瞬間**切換幾百萬個電晶體，每次切換都要對內部寄生電容充放電。

```
平均電流    500 mA           ← datasheet 上寫的
瞬間尖峰    幾 A，持續幾 ns   ← datasheet 不會寫
```

**這個尖峰，DC-DC 供得上嗎？供不上。**

```
DC-DC 的反應速度   微秒級（switching frequency 幾百 kHz ~ 幾 MHz）
晶片要的速度       奈秒級
```

慢了三個數量級。

---

## 電容的角色：本地的電荷水庫

```
DC-DC ────[走線電感]────┬──── 晶片 VCC 腳
                        │
                       ═╧═  去耦電容
                        │
                       GND
```

```
① 尖峰電流由電容就近供應（它離得近，來得及）
② DC-DC 慢慢把電容重新充滿（微秒級，來得及）
```

**電容不是「濾波」，是「代墊」。** 它墊付晶片瞬間要的電荷，之後再跟 DC-DC 報帳。

---

## ★ 為什麼要「靠近」—— 這才是重點

電容放得遠的話：

```
晶片 ──[10mm 走線]── 電容
        ↑ 這段走線有電感（約 1 nH/mm）
```

電感的特性是**反抗電流變化**：

```
V = L × (dI/dt)

10mm 走線 ≈ 10 nH
電流在 1 ns 內變化 1 A
→ V = 10nH × 1A/1ns = 10 V 的壓降
```

**十奈亨的電感，在 ns 級的電流變化下會產生數伏特的壓降。**
電容再大也沒用 —— 電荷被困在電感後面出不來。

```
0.1µF 小電容   ★ 緊貼每一支電源腳（最重要）
10µF 中電容    每組電源軌一顆，靠近進入點
100µF 大電容   整板輸入端
```

**距離的優先序高於容值。一顆放對位置的 0.1µF 勝過放遠的 10µF。**

---

## 為什麼要不同容值

每顆電容都有**自諧振頻率**（SRF）—— 超過那個頻率，它不再像電容，開始像電感。

```
100 µF    低頻有效（kHz 級）
10 µF     中頻
0.1 µF    高頻（MHz~百 MHz 級）  ← 對應數位切換的頻譜
```

**大電容管慢的、小電容管快的**，並聯涵蓋整個頻譜。

> 早年流行「0.1µF + 0.01µF 並聯」，但現代 MLCC 的 ESL 已經很低，
> 而且並聯不同容值可能產生反諧振 ——
> 實務上「多放幾顆同值 0.1µF」通常比「不同容值各一顆」有效。

---

## ★ 跟概念 ① 的連結：這也是一個電流迴路

```
電容 ──▶ 晶片 VCC 腳 ──▶ 晶片內部 ──▶ 晶片 GND 腳 ──▶ 回電容
```

**這個迴路的面積決定電感。** 所以不只電容要近，**回流路徑也要短**：

```
電容的 GND 端用最短的 via 接到 GND 平面
晶片的 GND 也用短 via 接到同一片平面
```

### 本專案的特殊狀況：EPAD 是唯一的數位地

**T113-S3 的 21 支電源，回流全部走 EPAD。**

```
EPAD 底下的 thermal via 不只是散熱
它是唯一的回流路徑
via 數量不夠 = 電感變大 = 去耦失效
```

這讓 `008-footprint.md` 的 thermal via 設計
從「散熱問題」升級成**「電源完整性問題」**。

---

## DC bias：ESP32 那塊板踩過的坑

MLCC 的容值會隨**直流偏壓**大幅衰減：

```
22 µF X7R 0805 標稱值
  @ 0V     22 µF
  @ 3.3V   ~17.6 µF   ← 掉 20%
  @ 5V     可能掉 50%
```

**封裝越小、標稱容值越大，掉得越兇。**
一顆 0402 的 10µF 在 3.3V 下可能只剩 3µF。

```
① 查 datasheet 的 DC bias 曲線，不要只看標稱值
② 標稱值留 2 倍餘裕
③ 或選大一級的封裝（0805 > 0603 > 0402）
```

⚠ 本專案被動件已決定改用 **0603**（手焊考量），
在 DC bias 上剛好也是比 0402 好的選擇。

---

## 一句話

**去耦電容是本地的電荷水庫，墊付晶片奈秒級的尖峰電流；
它有沒有用取決於「到晶片的迴路電感」——
所以位置比容值重要，回流路徑跟供電路徑一樣重要。**
