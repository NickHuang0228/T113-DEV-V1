# 概念 ① 回流路徑

> 這塊板的高速 layout 規則，大半是這一條的推論。

---

## 問題

訊號從晶片的腳出去，走過一條銅線，到另一顆晶片的腳。**那電流怎麼回來？**

電流必須形成完整迴路才能流動。但畫 PCB 時我們只畫「去」的那條線，從來不畫「回」的。

**回的那條，走地平面。**

```
        訊號線（你畫的）
   A ─────────────────────▶ B
   ▲                        │
   │   ← ← ← ← ← ← ← ← ←   ▼
   └──────── GND 平面 ──────┘
        回流（你沒畫，但它一定存在）
```

---

## 關鍵：高頻的回流不走最短路徑

```
低頻／直流   走電阻最低的路  →  地平面上兩點間的直線
高頻         走電感最低的路  →  訊號線的正下方
```

為什麼是正下方？去和回的電流方向相反，兩者圍出的**迴路面積**決定電感。
回流貼著訊號線正下方走，迴路面積最小 → 電感最小 → 阻抗最低。

**電流是懶的，它自動走阻抗最低的路。** 不需要你做什麼，它自己就貼在正下方。

---

## 地平面破一個洞

```
     訊號線 ──────────────────▶
     ═══════════════════════════
     GND 平面    ┌───────┐
                 │ 缺口  │        ← 這裡沒有銅
     ═══════════ └───────┘ ═══════

     回流被迫繞路 ↓
     ─────┐               ┌─────
          └───────────────┘
          迴路面積暴增
```

後果：

```
迴路面積變大  →  電感變大  →  訊號邊緣變鈍、時序偏移
              →  形成環形天線  →  對外輻射（EMI）
              →  也接收輻射    →  被干擾
```

---

## 這一條解釋了五個規則

| 文件裡的規則 | 其實是在說 |
|---|---|
| 差分不可跨分割 | 跨過去回流就沒路走 |
| L2 必須是完整一片 GND | 保證所有訊號正下方都有回流路徑 |
| 高速走 L1 參考 L2，不走 L4 | L4 下面是分割的電源層，回流會斷 |
| 換層時旁邊加 GND via | 訊號換層，回流也要跟著換，via 是它的橋 |
| **變壓器下方地平面挖空** | **反過來** — 刻意切斷，代價是那裡不能走訊號 |

最後一條特別注意：**挖空不是為了訊號好，是為了安規隔離。**
它刻意製造回流禁區，所以那塊區域不能有任何訊號經過 ——
`003-network.md` 寫「隔離區不放任何東西」，理由就在這裡。

---

## ⚠ 不要和「鋪銅」搞混

```
鋪銅（zone fill）   在訊號層的空白處填銅   ← ESP32 那塊板做的動作
參考平面            整層就是一片 GND       ← 這裡講的
```

**四層板上 L2 整層本來就是 GND，不需要你去「鋪」。**
你要做的不是「加上它」，而是**「不要破壞它」**。

### 三種破壞方式

```
① 在 L2 走訊號線        四層板空間不夠時最常見 —— 一條線就把平面切成兩半
② via 排成一列          密集的 via 形成「牆」，等同切斷
③ 把 L2 也拿來分割電源   本專案 L3 分電源、L2 純 GND，不要動
```

**第 ① 點是真正的誘惑**：layout 卡住時會想「L2 有大片空地，走一條就好」——
那一條線可能剛好切斷某個差分對的回流路徑，而且 **DRC 不會報錯**，
要到板子做出來才發現。

---

## 一句話

**你畫的每一條訊號線，正下方都必須有一片連續的銅，讓電流回家。**
