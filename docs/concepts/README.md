> 這塊板的設計文件有 6,000 多行，但**真正要內化的概念只有 8 條**。
>
> 其餘都是查證結果（「PC4/PC5 是 BOOT-SEL」「ADV7511 沒有 EPAD」），
> 那些不用記，畫到那裡再翻文件就好。
>
> 這個目錄裝的是要帶走的那 8 條。

## 讀法

一次一條，讀完能用自己的話講出那條「一句話」就算過。

**不用一口氣讀完。** 這 8 條會在畫原理圖和 layout 時反覆用到，
遇到不確定的地方回來翻，比一次背完有效。

---

## 這些概念為什麼重要

它們是「判斷方法」，不是「查證結果」：

```
查證結果   換一顆晶片就作廢
判斷方法   換十顆晶片都還在用
```

這塊板的目的是累積 layout 能力，而能力就長在這 8 條上面。
把它們搞懂，下一塊板（DP 探測板、SSD2832 板）可以直接沿用。
